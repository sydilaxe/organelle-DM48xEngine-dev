DM48X Tunings - send tuning files from the Organelle to a Lekholm DM48X

USE
1. Plug the DM48X into the Organelle's USB port. System > MIDI Setup >
   Device: pick the DM48X, Save. Load this patch.
2. On the DM48X: Tuning editor > step past the last hole > Receive tuning.
3. Knob 1: choose a tuning. Aux: send it. The screen says "Sent!".
4. On the DM48X, hold the round button 2 s on the Tuning page to save it
   to a slot (received tunings are lost at power-off until saved).
   Don't press the Organelle keys while the DM48X is receiving.

ADD YOUR OWN
  Put .mid files in this folder (e.g. a tuning recorded from the DM48X's
  "Send tuning"). Notes are sent in file order; other MIDI data is skipped.

FIRST TIME: send "Order test" and check a few notes in the Tuning editor:
  hole 1 blow = C3 (MIDI 48), hole 1 draw = C4 (60),
  hole 1 blow+slider = C5 (72), hole 12 draw+slider = B6 (95).
  If those match, every file here is in the right order. If they don't,
  stop and tell me what the editor shows - nothing is saved until you save.

The tunings are listed note by note in TUNINGS.txt. For the four
"Richter Low" harps use MPE Super JI in the same key with Tuning = Just.
